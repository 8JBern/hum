# Decisions

- D-01 Title: the coordinator's title search found HUM taken (Steam "HUM" by NO JOY, itch.io "The Hum" with a near-identical premise). Chosen title: **FIFTY HERTZ**, which ties directly to the 50 Hz mains hum mechanic and was reported unclaimed on Steam and itch.io. The repository stays `hum`, and the internal code name and test hook stay `HUM` / `window.__HUM__` as the brief requires. Share strings use `FIFTY HERTZ Daily`.
- D-02 Timeline: the build started at 06:21 Brisbane on 25 November 2026, not overnight. The 06:45 hard stop assumes an overnight start, so milestone windows are treated as elapsed time from the start (T = 06:21) and the Freeze phase begins at T+6:30, not at 06:45 today.
- D-03 Versions (checked on npm at start): three 0.187.0, vite 8.3.8, vitest 5.1.1, typescript 5.9.3 (5.x chosen over 7.x for tooling stability), @playwright/test 1.63.0 pinned to match the Chromium build pre-installed in the environment.
- D-04 Lighting: fluorescent panels sit on a fixed 4 m world grid. One custom world shader evaluates the nearest panels analytically per pixel, with dead, dimmed and flickering panels chosen by the same integer hash in TypeScript and GLSL. This gives per-pixel coverage with zero dynamic lights and few draw calls.
- D-05 World generation: 16 x 16 cell chunks, 2 m cells. Borders are shared lines whose doorways come from a hash of the line, so neighbours agree. Interiors use binary space partitioning where every split wall has at least one doorway, which guarantees connectivity by construction; the unit test proves it with breadth-first search.
- D-06 Archive unlocks are automatic when banked Evidence crosses each cost. No spending decisions, no scarcity.
- D-07 Reused the tested seeded generator from the project's generator thread (`src/world/chunk.ts`, `navigation.ts`, `src/core/rng.ts` and their tests) rather than rebuilding it. Furniture, cubicle partitions (wall value 3), anomalies and pickups are layered on top in `src/world/content.ts`, which keeps the pinned layout hashes stable.
- D-08 Anomaly density rises with depth (level) and with distance from the spawn chunk, which stands in for run time. Generation stays a pure function of (seed, level, chunk), so a chunk is identical whenever it is streamed in.
- D-09 It moves when you look away (P2-02): when the tab returns after more than 5 seconds hidden, loaded chunks outside the player's chunk get a new furnishing variant (props and anomalies), never walls, so navigation stays fair. Skipped when the Occupant is within 14 m.
- D-10 Your last tape (P2-01): only death tapes are kept (`save.lastTape` stores seed, level, time and frames). In the next run the lost camcorder lies in a reachable room of a neighbouring chunk. Picking it up regenerates the old world from its seed in a temporary scene and plays the CCTV replay there, then disposes it.
- D-11 Photo mode (P2-08) is an Archive unlock at 100 banked Evidence; once unlocked it is entered from the pause menu, which freezes the world and hides the HUD.
- D-12 Touch controls (P2-07) appear only after the first touch event and only during play: left half is a floating move stick, right half drags to look, with CAM, SNAP, USE, IR and pause buttons. Pinch zoom is left enabled for accessibility.
- D-13 Level C "P4" (P2-05) is not built. The time was spent on testing, the last tape and touch controls, which reach more players. The Archive therefore has no Level C unlock.
- D-14 The deployed smoke test runs as a `smoke` job in the Pages workflow after deploy, because this build environment's proxy refuses github.io. `npm run test:deployed` still works locally on any normal network.
